# Seleção Brasileira

Projeto desenvolvido para a disciplina de Laboratório de Algoritmos e Estruturas de Dados I, do curso de **Ciência da Computação** da PUC Minas.

**Integrantes:**

- Christian
- Gabriel
- José Elias

## Sobre o projeto

O programa funciona como um **CRUD** simples no terminal: o usuário cadastra, lista, edita, exclui e pesquisa jogadores convocados, além de consultar estatísticas.

## Como executar

Usuários de **Windows** podem baixar o executável na aba Releases.

**Para Linux / MacOS:**

É necessário ter um compilador C instalado (por exemplo, o **GCC**).

1. Clone o repositório:

    ```bash
    git clone https://github.com/christianrodriguess/selecao-brasileira.git
    cd selecao-brasileira
    ```

2. Compile o código:

    ```bash
    gcc src/selecaoBrasileira.c -o build/selecaoBrasileira
    ```

3. Execute:

    ```bash
    ./build/selecaoBrasileira
    ```
